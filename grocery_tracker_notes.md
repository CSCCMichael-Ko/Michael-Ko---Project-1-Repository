## Project Overview: 
I would like to create a program that can help me track my money/track the money I spent during groceries.
The program would "write down" grocery items bought after shopping and would show if I was within a budget.
- Taking inspiration from the Participation Activity 1 Try it Yourself programs
### Chosen Project: Grocery/Budget Tracker (1)
- This project would involve inputting what groceries are bought at what price (prices would be inputted)
- A "total" would show up (how much was spent)
- How much was spent (total) would be compared to a hard budget set. 
- The hard budget would be set by me, based on how much I should spent
- If budget is over, print() statement reminding me to be on budget for next week..?
